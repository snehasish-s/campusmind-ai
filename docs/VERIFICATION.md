## Execution boundaries

The Linux Docker engine was unavailable in the earlier infrastructure checks. PostgreSQL, Redis/RQ, Mailpit, Ollama and remote Qdrant containers were not run. SMTP acceptance uses captured synthetic email. Local-model tests use a controlled stub; vector adapter tests use real in-process Qdrant with controlled vectors. Actual Ollama inference, Sentence Transformers weights and vector/hybrid quality evaluation remain unverified.

Supabase Storage transport and payment-provider capture calls are tested with mocked HTTP. This extension was verified against isolated local synthetic records; no live merchant checkout, bank settlement, cloud deployment or live cloud migration is claimed. Offline PostgreSQL compilation and SQLite integration tests do not substitute for those checks.

Campus updates refresh by polling every 15 seconds. Optional browser alerts work while the application is open; background Web Push is not implemented. Timetable routing requires trusted administrative setup. Read acknowledgement is explicit. Assignment submissions, faculty grading and durable idempotent scheduled reminders are now implemented. Free Render hosts cannot execute reminders while asleep; they catch up after wake-up. Optional Odia translation requires a local model and human review; model quality was not evaluated.

Before real institutional use, complete independent security/privacy review, live PostgreSQL isolation/concurrency testing, deployment/load testing, backup recovery and support operations. The small synthetic AI benchmark is not a claim of real-world student proficiency, hiring outcomes or accreditation compliance.
